# ffmpeg クリップ編集コマンド生成ツール（簡易仕様）

## 概要
よく使う動画編集操作をフォーム入力から選び、ffmpeg コマンドを 1 行で自動生成するツール。

## 初回実装の前提
- 実装方式は HTML + Vanilla JS
- 画面は単一の index.html で構成する
- UI 表示は日本語のみ
- 出力は 1 行の ffmpeg コマンドのみ
- 画面上部に「操作選択」を持たせる

## 操作選択
- 動画カット
- 先頭 / 末尾カット
- 速度変更
- フェードイン / フェードアウト

## 入力項目

### 基本
- 入力ファイル名（初期値: input.mp4）
- 出力ファイル名（初期値: output.mp4）

### 動画カット
- 開始時間（例: 00:01:30）
- 終了時間（例: 00:02:00）

### 先頭 / 末尾カット
- カット対象（先頭 / 末尾）
- 基準時刻（例: 00:01:30）

### 速度変更
- 速度倍率（例: 1.25）

### フェードイン / フェードアウト
- フェード種類（フェードイン / フェードアウト / 両方）
- フェード時間（秒）
- フェードアウト開始時刻（フェードアウトを使う場合のみ）

### モード
- 動画カット、先頭 / 末尾カットで使用
- コピー（無劣化・高速）
- 再エンコード（低速・細かい調整向き）

### エンコード設定
- 動画コーデック（例: libx264 / libx265）
- 音声コーデック（例: aac / mp3 / copy）
- preset（例: ultrafast / veryfast / medium）

補足:
- 速度変更とフェードでは再エンコード固定とする
- 速度変更とフェードで音声を残す場合、音声コーデックに copy は使わない

### オプション（任意）
- 解像度（例: 1280x720）
- フレームレート（例: 30）
- 音声なし（ON/OFF）
- 上書き（ON/OFF）

## 画面要件
- フォーム形式で入力できる
- 選択した操作に必要な入力だけを表示する
- 必要な入力が揃うと自動でコマンドをプレビュー生成する
- 生成結果は読み取り専用テキストエリアに表示する
- コピーボタンでコマンドをコピーできる
- 入力エラーは結果欄の近くに日本語で表示する

## コマンド生成ルール

### 共通
- 時間指定は HH:MM:SS 形式で扱う
- ファイル名は引用符付きで出力する
- 上書きが ON のときのみ -y を付与する

### 動画カット
- 内部では 終了時間 - 開始時間 を計算して長さを算出し、-t に変換する

コピー:
- -ss を入力前に配置する
- -c copy を固定で使用する
- 音声なしが ON の場合のみ -an を追加する

再エンコード:
- -ss を入力後に配置する
- 動画コーデック、音声コーデック、preset を使用する
- 音声なしが ON の場合は -an を優先し、音声コーデック入力は UI 上で無効化する
- 解像度入力時は -s、フレームレート入力時は -r を追加する

### 先頭 / 末尾カット
- 先頭カットは指定時刻より前を削除する
- 末尾カットは動画の先頭から指定時刻までを残す

コピー:
- 先頭カットは -ss を入力前に配置する
- 末尾カットは -t を入力後に配置する
- -c copy を固定で使用する
- 音声なしが ON の場合のみ -an を追加する

再エンコード:
- 先頭カットは -ss を入力後に配置する
- 末尾カットは -t を入力後に配置する
- 動画コーデック、音声コーデック、preset を使用する
- 音声なしが ON の場合は -an を優先し、音声コーデック入力は UI 上で無効化する
- 解像度入力時は -s、フレームレート入力時は -r を追加する

### 速度変更
- 再エンコード固定
- 映像は setpts フィルタで速度変更する
- 音声を残す場合は atempo フィルタで速度変更する

### フェードイン / フェードアウト
- 再エンコード固定
- 映像は fade フィルタを使う
- 音声を残す場合は afade フィルタも併用する
- フェードアウト開始時刻は動画先頭からの絶対位置で指定する

## バリデーション
- 入力ファイル名は必須
- 出力ファイル名は必須
- 動画カットでは開始時間と終了時間が必須
- 動画カットでは 開始時間 < 終了時間 を満たすこと
- 先頭 / 末尾カットでは基準時刻が必須
- 先頭 / 末尾カットでは 00:00:00 は指定不可
- 速度変更では速度倍率が必須で、0.25 から 4.0 の範囲とする
- 速度変更では 1.0 は指定不可
- フェードではフェード時間が必須で、0 より大きい値とする
- フェードアウトを使う場合はフェードアウト開始時刻が必須
- 速度変更とフェードで音声を残す場合、音声コーデックに copy は指定不可
- 解像度は未入力または 幅x高さ 形式
- フレームレートは未入力または正の数値
